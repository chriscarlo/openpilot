# Branch Protection Hook for Chauffeur Development
# This hook prevents accidental branch switches during development

## Hook Configuration Files Required:

### 1. `.claude/settings.json`:

```json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "python3 $CLAUDE_PROJECT_DIR/.claude/hooks/block-branch-changes.py"
          }
        ]
      }
    ]
  }
}
```

### 2. `.claude/hooks/block-branch-changes.py`:

```python
#!/usr/bin/env python3
"""
Project-level hook to prevent branch changes in the Chauffeur openpilot fork.
Blocks git checkout and git clone commands to maintain chauffeur-dev2 branch integrity.
"""

import sys
import json
import re

def main():
    try:
        # Debug: Log that hook was called
        with open('/tmp/hook-debug.log', 'a') as f:
            f.write("Hook called at: " + str(sys.argv) + "\n")
        
        # Read the tool input from stdin
        data = json.load(sys.stdin)
        
        # Debug: Log the data received
        with open('/tmp/hook-debug.log', 'a') as f:
            f.write(f"Data received: {json.dumps(data)}\n")
        
        # Extract command if it's a Bash tool call
        tool_name = data.get('tool_name', '')
        tool_input = data.get('tool_input', {})
        command = tool_input.get('command', '')
        
        # Only process Bash tool calls
        if tool_name != 'Bash':
            # Allow non-Bash tools
            sys.exit(0)
        
        # Define patterns for blocked git commands
        blocked_patterns = [
            # Block git checkout of different branches
            r'git\s+checkout\s+(?!chauffeur-dev2)',
            # Block git switch to different branches  
            r'git\s+switch\s+',
            # Block git clone (prevents cloning other repos)
            r'git\s+clone\s+',
            # Block git fetch followed by checkout
            r'git\s+fetch.*&&.*git\s+checkout',
            # Block git pull from different branches
            r'git\s+pull\s+\w+\s+(?!chauffeur-dev2)',
            # Block branch creation commands
            r'git\s+checkout\s+-b\s+',
            r'git\s+branch\s+(?!-l|-a|-r|-d|-D|--list|--delete)',
        ]
        
        # Check if command matches any blocked pattern
        for pattern in blocked_patterns:
            if re.search(pattern, command, re.IGNORECASE):
                # Block the command with detailed message
                blocking_response = {
                    "hookSpecificOutput": {
                        "hookEventName": "PreToolUse",
                        "permissionDecision": "deny",
                        "permissionDecisionReason": (
                            "🚫 BRANCH PROTECTION ACTIVE: This command would change the current branch.\n\n"
                            "The Chauffeur project is locked to branch 'chauffeur-dev2' to maintain:\n"
                            "• Feature development consistency\n"
                            "• Codebase integrity\n"
                            "• Prevention of accidental branch switches\n\n"
                            f"Blocked command: {command}\n\n"
                            "If you need to view other branches, use:\n"
                            "• git log origin/<branch> --oneline\n"
                            "• git diff chauffeur-dev2..origin/<branch>\n"
                            "• git show origin/<branch>:path/to/file\n\n"
                            "To disable this protection, remove the hook from .claude/settings.json"
                        )
                    }
                }
                print(json.dumps(blocking_response))
                sys.exit(2)  # Exit code 2 blocks the tool call
        
        # Allow commands that don't change branches
        safe_git_commands = [
            'git status',
            'git log',
            'git diff',
            'git add',
            'git commit',
            'git push',
            'git stash',
            'git show',
            'git branch -l',
            'git branch --list',
            'git branch -a',
            'git branch -r',
            'git remote',
            'git fetch'
        ]
        
        # Check if it's a safe git command (optional feedback)
        if any(command.strip().startswith(cmd) for cmd in safe_git_commands):
            # Silently allow safe commands
            sys.exit(0)
        
        # Allow all other commands
        sys.exit(0)
        
    except Exception as e:
        # In case of error, log but don't block
        print(f"Hook error: {e}", file=sys.stderr)
        sys.exit(0)

if __name__ == "__main__":
    main()
```

## Installation:

1. Create `.claude/settings.json` in your project root with the JSON configuration above
2. Create `.claude/hooks/block-branch-changes.py` with the Python script above
3. Make the Python script executable: `chmod +x .claude/hooks/block-branch-changes.py`
4. The hook will immediately prevent branch switches

## What This Hook Does:

**Blocks these git commands:**
- `git checkout` (to different branches)
- `git switch`
- `git clone`
- `git fetch && git checkout`
- `git pull` from different branches
- `git checkout -b` (new branch creation)
- `git branch` (except list/delete operations)

**Allows these git commands:**
- `git status`, `git log`, `git diff`
- `git add`, `git commit`, `git push`
- `git stash`, `git show`
- `git branch -l`, `git branch --list`, `git branch -a`, `git branch -r`
- `git remote`, `git fetch` (standalone)

## Testing:

Try running `git checkout main` and you should see the protection message.

## Debug Logging:

The hook writes debug logs to `/tmp/hook-debug.log` to help troubleshoot issues.

## Important Notes:

- Uses the modern `PreToolUse` hook event (not the deprecated `tool-invocation`)
- Requires Python 3
- Exit code 2 blocks the tool call
- The hook receives tool data via stdin as JSON
